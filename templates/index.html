Algorithm in short

  1. Build a 4×4 state: 4 constants, 8 key words, 1 counter, 3 nonce words.
  2. Run 20 rounds of Quarter Rounds (add, XOR, rotate) on the state.
  3. Add the original state back → this is the 64-byte keystream.
  4. XOR the keystream with the plaintext → ciphertext.
